# PDF Viewer Online

A browser-based PDF viewer built with HTML, CSS, JavaScript, and the bundled PDF.js library.

## Live demo

[Open PDF Viewer Online](https://obaidhqbd.github.io/PDF-Viewer-Online/)

## Features

- Open a PDF from a local file or an accessible URL.
- Move between pages or jump to a page number.
- Zoom in and out.
- Print or download the document.
- Switch between light and dark themes.

## Run locally

Serve the repository as a static website and open it in a modern browser. No package manager or build step is required. Loading a PDF from another website depends on that host allowing cross-origin access.

## Technology

HTML5, CSS3, JavaScript, and a locally bundled PDF.js viewer and worker.
